# Security policy

Report vulnerabilities privately to the repository owner; do not include sensitive user data in a public issue.

Version 1.0 uses password hashing, CSRF protection for browser mutations, short-lived signed API tokens, owner-scoped private queries, upload extension/size limits, non-public document storage, secure production cookies, proxy-aware HTTPS URLs, and baseline browser security headers.

Operators are responsible for unique secrets, TLS, database and upload access controls, encrypted off-host backups, dependency updates, and log redaction. AI assistance is disabled unless explicitly configured and sends data only after a user submits the assistance form.
